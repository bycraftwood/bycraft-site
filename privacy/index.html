2. Цели обработки персональных данных

Оператор обрабатывает только те персональные данные, которые необходимы для осуществления ремесленной и творческой деятельности:

3. Перечень обрабатываемых данных

При добровольном обращении через формы сайта, электронную почту, телефон или мессенджеры Оператор может обрабатывать:

Сайт использует технические файлы cookie, необходимые для поддержания сессии пользователя, фиксации согласия на использование cookie и адаптивного отображения материалов на экранах различных устройств.

Персональные данные хранятся не дольше, чем этого требуют цели их обработки, и удаляются по достижении целей либо при отзыве согласия пользователем.
